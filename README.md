# AI Blog

Современный блог на основе Markdown с хостингом на GitHub Pages.

## Особенности

- 📝 **Markdown статьи** — пишите контент в удобном формате Markdown
- ❤️ **Лайки** — функция лайков через localStorage
- 🔍 **Поиск** — быстрый поиск по всем статьям (⌘K / Ctrl+K)
- 🌓 **Тёмная тема** — переключение между светлой и тёмной темой
- 📱 **Адаптивный дизайн** — отлично выглядит на всех устройствах
- ⚡ **Автоматический индекс** — GitHub Actions автоматически обновляет список статей

## Структура проекта

```
├── index.html              # Главная страница
├── css/
│   └── style.css          # Стили (GitBook/GitHub стиль)
├── js/
│   ├── app.js             # Основное приложение
│   └── marked.min.js      # Markdown парсер
├── pages/
│   ├── articles.json      # Автогенерируемый индекс статей
│   └── *.md               # Ваши markdown статьи
└── .github/
    └── workflows/
        └── update-pages.yml  # Workflow для обновления индекса
```

## Как добавить статью

1. Создайте `.md` файл в папке `pages/`
2. Добавьте frontmatter:

```yaml
---
title: 'Заголовок статьи'
description: 'Краткое описание'
date: '2025-01-15'
author: 'Ваше имя'
tags: ['tag1', 'tag2']
---
```

3. Напишите содержимое в Markdown
4. Закоммитьте и отправьте в репозиторий

## Развёртывание на GitHub Pages

1. Зайдите в настройки репозитория
2. Перейдите в раздел **Pages**
3. Выберите ветку `main` и папку `/ (root)`
4. Сохраните — сайт будет доступен через несколько минут

## Локальная разработка

Просто откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

## Технологии

- HTML5, CSS3, Vanilla JavaScript
- [Marked](https://marked.js.org/) — Markdown парсер
- Google Fonts (Inter, JetBrains Mono)
- GitHub Actions для автоматизации
