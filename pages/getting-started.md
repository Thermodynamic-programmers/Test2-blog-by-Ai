# Начало работы с AI Blog

Добро пожаловать в **AI Blog** — современную платформу для ведения блога о технологиях и искусственном интеллекте.

## Что такое AI Blog?

AI Blog — это статический сайт-блог, который:

- Хостится на GitHub Pages
- Использует Markdown для написания статей
- Автоматически генерирует индекс статей через GitHub Actions
- Поддерживает тёмную тему
- Имеет встроенный поиск
- Позволяет лайкать статьи (сохраняется в localStorage)

## Как добавить новую статью

1. Создайте новый `.md` файл в папке `pages/`
2. Добавьте frontmatter в начале файла:

```yaml
---
title: 'Заголовок статьи'
description: 'Краткое описание статьи'
date: '2025-01-15'
author: 'Ваше имя'
tags: ['tag1', 'tag2', 'tag3']
---
```

3. Напишите содержимое статьи в формате Markdown
4. Закоммитьте и отправьте изменения в репозиторий
5. GitHub Actions автоматически обновит индекс статей

## Особенности платформы

### 🔍 Поиск

Нажмите `⌘K` (или `Ctrl+K`) для быстрого поиска по всем статьям.

### ❤️ Лайки

Каждую статью можно лайкнуть. Количество лайков сохраняется в `localStorage` браузера.

### 🌓 Тёмная тема

Переключатель темы находится в нижней части боковой панели.

### 📱 Адаптивный дизайн

Сайт полностью адаптивен и отлично выглядит на мобильных устройствах.
